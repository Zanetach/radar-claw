# Radar Content Workflow

## Operating Boundary

Radar is the backend system of record for source accounts, raw collected content, media metadata, organized content, publish status, and run reports. The product entry is the Hermes/Qianfeng AI Agent. Hermes performs intelligent work through Radar MCP tools and must write results back to Radar.

Use the Radar MCP tools instead of editing Radar files directly.

Do not direct end users to Radar Web for normal operation. Radar Web, if running locally, is an internal debug/admin console for developers and operators.

## Roles

These roles are capability templates, not mandatory fixed agents. A Qianfeng/Hermes AI employee can bind only the collection capability, or bind collection plus organization, or split collection/organization/publishing into separate employees. Radar remains the shared data and task layer.

### 数据采集 Agent

Use only collection tools:

- `radar_list_strategies`
- `radar_create_employee_task` with `agent_type="crawler"`
- `radar_create_crawl_run`
- `radar_get_run_report`
- `radar_update_task_status`

Rules:

- Create raw data only. Do not translate, summarize, approve, or publish.
- Prefer a named strategy from `radar_list_strategies`.
- For X production, prefer XMCP/API strategies. For free validation, use `X 免费 x-rss 情报源`.
- Preserve source URLs and media metadata.

### 内容整理 Agent

Use only raw-content and organization tools:

- `radar_list_raw_contents`
- `radar_get_raw_content_detail`
- `radar_handoff_to_organizer`
- `radar_save_translation_result`
- `radar_save_organized_content`
- `radar_update_task_status`

Rules:

- Organize only content that already exists in Radar raw data.
- Never trigger a new crawl from the organizer role.
- Preserve English original text exactly in the original field.
- Write Chinese translation to `translated_text_zh`.
- If OCR is unavailable, leave OCR fields empty and mark the issue in `organize_notes`.
- Provide `quality_score`, `quality_reason`, `content_category`, and a concise publish recommendation.
- Only mark `review_status="approved"` when the content is suitable for publishing.
- When receiving an organizer task, read `organizer_task.handoff.items` and write back every accepted item with `radar_save_organized_content`.

### 内容发布 Agent

Use only organized/publish tools:

- `radar_list_organized_contents`
- `radar_list_publishable_contents`
- `radar_publish_contents`
- `radar_get_run_report`
- `radar_update_task_status`

Rules:

- Publish only organized content.
- Never publish raw unorganized content.
- Always include source URL in the publish payload or notes.
- If publishing fails, update task status and keep the item retryable.

## Required Output Shape For Organization

When saving organized content, provide:

- `organized_title`
- `organized_summary`
- `translated_text_zh`
- `quality_score`
- `quality_reason`
- `content_category`
- `organize_notes`
- `review_status`
- `publish_status`

Markdown generated by Radar must include:

- 原文
- 中文翻译
- 图片 OCR 原文
- 图片 OCR 中文
- 摘要
- 质量建议
- 分类
- 媒体
- 原文链接

## Safety

- Do not bypass platform login, paywalls, CAPTCHA, or rate limits.
- Do not expose tokens in messages.
- Do not fabricate metrics that were not returned by providers.
- Use `metrics_pending` or explanatory notes when metrics are unavailable.
