前置只需要配置 X MCP / Token / Hermes MCP。后续从采集、筛选、整理到定向发布，都通过同一个状态流完成。

系统就绪度 检测中
1

采集 Agent

从 X MCP、账号源或 Excel 生成原始数据，保留原文链接、图片和视频元数据。

2

整理 Agent

只读取已采集原始数据，生成质量建议、中文整理、OCR、分类和归档内容。

3

发布 Agent

只读取整理库和待发布队列，按雷达号 APP、小红书或自定义渠道定向发布。
