## 【发布】动态


**接口地址**:`/api/app/moment/publish`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>发布图文/视频/文件类型的动态</p>



**请求示例**:


```javascript
{
  "momentId": 0,
  "momentType": "",
  "title": "",
  "contentText": "",
  "cardUserId": 0,
  "contentRich": "",
  "mediaCount": 0,
  "visibility": "",
  "tagIdList": [],
  "atUserIds": [],
  "locLongitude": "",
  "locLatitude": "",
  "locName": "",
  "locAddress": "",
  "mediaList": [
    {
      "mediaType": "",
      "url": "",
      "thumbnailUrl": "",
      "thumbnailWidth": 0,
      "thumbnailHeight": 0,
      "imageWidth": 0,
      "imageHeight": 0,
      "fileName": "",
      "fileExt": "",
      "fileSize": 0,
      "videoDuration": 0,
      "sortOrder": 0
    }
  ],
  "topicList": [
    {
      "topicId": 0,
      "topicName": ""
    }
  ]
}
```

**响应状态**:


| 状态码 | 说明 | schema           |
| ------ | ---- | ---------------- |
| 200    | OK   | ApiResultBoolean |
