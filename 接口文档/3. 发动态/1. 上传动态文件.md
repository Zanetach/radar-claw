## 【上传】媒体文件


**接口地址**:`/api/app/moment/upload/media`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>只用于上传动态的媒体文件</p>



**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | schema |
| -------- | -------- | -------- | -------- | -------- | ------ |
| file     |          | query    | true     | file     |        |


**响应状态**:


| 状态码 | 说明 | schema                     |
| ------ | ---- | -------------------------- |
| 200    | OK   | ApiResultCosUploadResponse |


**响应参数**:


| 参数名称                 | 参数说明     | 类型              | schema            |
| ------------------------ | ------------ | ----------------- | ----------------- |
| code                     | 自定义响应码 | string            |                   |
| message                  | 响应信息     | string            |                   |
| data                     |              | CosUploadResponse | CosUploadResponse |
| &emsp;&emsp;success      |              | boolean           |                   |
| &emsp;&emsp;url          |              | string            |                   |
| &emsp;&emsp;key          |              | string            |                   |
| &emsp;&emsp;fileName     |              | string            |                   |
| &emsp;&emsp;fileSize     |              | integer(int64)    |                   |
| &emsp;&emsp;contentType  |              | string            |                   |
| &emsp;&emsp;etag         |              | string            |                   |
| &emsp;&emsp;errorMessage |              | string            |                   |
| param                    | 额外参数     | object            |                   |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {
		"success": true,
		"url": "",
		"key": "",
		"fileName": "",
		"fileSize": 0,
		"contentType": "",
		"etag": "",
		"errorMessage": ""
	},
	"param": {}
}
```
