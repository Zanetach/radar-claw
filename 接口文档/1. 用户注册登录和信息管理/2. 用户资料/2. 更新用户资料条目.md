## 更新用户资料条目


**接口地址**:`/api/app/user/profile/item`


**请求方式**:`PUT`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>更新用户的可提供资源、需要的资源或个人成就</p>



**请求示例**:


```javascript
{
  "userId": 123456789,
  "id": 987654321,
  "itemType": "OFFER",
  "content": "我可以提供专业的编程咨询服务",
  "images": [
    "https://example.com/image1.jpg",
    "https://example.com/image2.jpg"
  ]
}
```


**请求参数**:


**请求参数**:


| 参数名称                 | 参数说明                                                     | 请求类型 | 是否必须 | 数据类型                 | schema                   |
| ------------------------ | ------------------------------------------------------------ | -------- | -------- | ------------------------ | ------------------------ |
| userProfileItemUpdateDTO | 用户资料条目更新请求DTO                                      | body     | true     | UserProfileItemUpdateDTO | UserProfileItemUpdateDTO |
| &emsp;&emsp;userId       | 用户ID                                                       |          | true     | integer(int64)           |                          |
| &emsp;&emsp;id           | 条目ID（更新时必填，新增时不填）                             |          | false    | integer(int64)           |                          |
| &emsp;&emsp;itemType     | 条目类型:OFFER-可提供资源 NEED-需要资源 ACHIEVEMENT-个人成就,可用值:OFFER,NEED,ACHIEVEMENT,OFFER,NEED,ACHIEVEMENT |          | true     | string                   |                          |
| &emsp;&emsp;content      | 条目内容                                                     |          | false    | string                   |                          |
| &emsp;&emsp;images       | 图片URL列表(JSON数组)                                        |          | false    | array                    | string                   |


**响应状态**:


| 状态码 | 说明 | schema        |
| ------ | ---- | ------------- |
| 200    | OK   | ApiResultVoid |


**响应参数**:


| 参数名称 | 参数说明     | 类型   | schema |
| -------- | ------------ | ------ | ------ |
| code     | 自定义响应码 | string |        |
| message  | 响应信息     | string |        |
| data     | 响应数据     | object |        |
| param    | 额外参数     | object |        |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {},
	"param": {}
}
```
