## 更新用户基础资料


**接口地址**:`/api/app/user/profile`


**请求方式**:`PUT`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>更新用户昵称、头像、性别等基础信息</p>



**请求示例**:


```javascript
{
  "id": 0,
  "nickname": "",
  "avatar": "",
  "gender": "MALE/FEMALE/UNKNOWN",
  "birthday": "",
  "maritalStatus": "SINGLE/MARRIED/DIVORCED/SECRET",
  "height": 0,
  "weight": 0,
  "currentResidence": "",
  "hometown": "",
  "education": "OTHER/JUNIOR_COLLEGE/BACHELOR/MASTER/DOCTOR",
  "occupation": ""
}
```


**请求参数**:


**请求参数**:


| 参数名称                     | 参数说明                                                | 请求类型 | 是否必须 | 数据类型             | schema               |
| ---------------------------- | ------------------------------------------------------- | -------- | -------- | -------------------- | -------------------- |
| userProfileUpdateDTO         | 更新用户资料请求                                        | body     | true     | UserProfileUpdateDTO | UserProfileUpdateDTO |
| &emsp;&emsp;id               | 用户ID                                                  |          | true     | integer(int64)       |                      |
| &emsp;&emsp;nickname         | 昵称                                                    |          | true     | string               |                      |
| &emsp;&emsp;avatar           | 头像URL                                                 |          | false    | string               |                      |
| &emsp;&emsp;gender           | 性别,可用值:MALE,FEMALE                                 |          | true     | string               |                      |
| &emsp;&emsp;birthday         | 出生日期                                                |          | true     | string(date)         |                      |
| &emsp;&emsp;maritalStatus    | 婚姻状态,可用值:SINGLE,MARRIED,DIVORCED,SECRET          |          | false    | string               |                      |
| &emsp;&emsp;height           | 身高(cm)                                                |          | false    | integer(int32)       |                      |
| &emsp;&emsp;weight           | 体重(kg)                                                |          | false    | number               |                      |
| &emsp;&emsp;currentResidence | 现居地                                                  |          | true     | string               |                      |
| &emsp;&emsp;hometown         | 家乡                                                    |          | true     | string               |                      |
| &emsp;&emsp;education        | 学历,可用值:OTHER,JUNIOR_COLLEGE,BACHELOR,MASTER,DOCTOR |          | false    | string               |                      |
| &emsp;&emsp;occupation       | 职业                                                    |          | true     | string               |                      |


**响应状态**:


| 状态码 | 说明 | schema        |
| ------ | ---- | ------------- |
| 200    | OK   | ApiResultVoid |


**响应参数**:


| 参数名称 | 参数说明     | 类型   | schema |
| -------- | ------------ | ------ | ------ |
| code     | 自定义响应码 | string |        |
| message  | 响应信息     | string |        |
| data     | 响应数据     | object |        |
| param    | 额外参数     | object |        |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {},
	"param": {}
}
```
