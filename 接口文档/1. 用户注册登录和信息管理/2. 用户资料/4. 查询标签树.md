## 查询标签树


**接口地址**:`/api/app/user/tags/tree`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>根据标签类型查询标签树结构，支持个性标签、行业标签、职业标签</p>



**请求参数**:


**请求参数**:


| 参数名称 | 参数说明                                                     | 请求类型 | 是否必须 | 数据类型 | schema |
| -------- | ------------------------------------------------------------ | -------- | -------- | -------- | ------ |
| tagType  | 标签类型:PERSONALITY-个性标签 INDUSTRY-行业标签 OCCUPATION-职业标签,可用值:PERSONALITY,INDUSTRY,OCCUPATION,POSITION | query    | true     | string   |        |


**响应状态**:


| 状态码 | 说明 | schema                      |
| ------ | ---- | --------------------------- |
| 200    | OK   | ApiResultListUserTagsTreeVO |


**响应参数**:


| 参数名称             | 参数说明                                                     | 类型           | schema         |
| -------------------- | ------------------------------------------------------------ | -------------- | -------------- |
| code                 | 自定义响应码                                                 | string         |                |
| message              | 响应信息                                                     | string         |                |
| data                 | 响应数据                                                     | array          | UserTagsTreeVO |
| &emsp;&emsp;id       | 标签ID                                                       | integer(int64) |                |
| &emsp;&emsp;pid      | 父级ID                                                       | integer(int64) |                |
| &emsp;&emsp;deep     | 层级                                                         | integer(int64) |                |
| &emsp;&emsp;sort     | 排序                                                         | integer(int64) |                |
| &emsp;&emsp;tagType  | 标签类型：PERSONALITY-个性标签, INDUSTRY-行业标签, OCCUPATION-职业标签,可用值:PERSONALITY,INDUSTRY,OCCUPATION,POSITION | string         |                |
| &emsp;&emsp;tagName  | 标签名称                                                     | string         |                |
| &emsp;&emsp;tagLevel | 标签层级：1-一级分类，2-二级具体标签                         | integer(int32) |                |
| &emsp;&emsp;tagOrder | 显示顺序                                                     | integer(int32) |                |
| &emsp;&emsp;status   | 状态：NORMAL-正常, DISABLED-禁用,可用值:NORMAL,DISABLED      | string         |                |
| &emsp;&emsp;children | 子标签列表                                                   | array          | UserTagsTreeVO |
| param                | 额外参数                                                     | object         |                |
