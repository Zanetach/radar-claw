## AI雷达号密码登录


**接口地址**:`/api/auth/ai/login/password`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>AI 端使用 雷达号与密码登录，token 仅适用于 /ai/**</p>



**请求示例**:


```javascript
{
  "radarNumber": "12345678",
  "password": "password123",
  "clientId": "",
  "source": "OTHER"
}
```


**请求参数**:


**请求参数**:


| 参数名称                | 参数说明                                   | 请求类型 | 是否必须 | 数据类型           | schema             |
| ----------------------- | ------------------------------------------ | -------- | -------- | ------------------ | ------------------ |
| aiPasswordLoginDTO      | AI 用户雷达号密码登录 DTO                  | body     | true     | AiPasswordLoginDTO | AiPasswordLoginDTO |
| &emsp;&emsp;radarNumber | 雷达号                                     |          | true     | string             |                    |
| &emsp;&emsp;password    | 密码                                       |          | true     | string             |                    |
| &emsp;&emsp;clientId    | 固定值为: 0f07364c2d1a4090a71984147e57c07d |          | true     | string             |                    |
| &emsp;&emsp;source      | 登录来源,可用值:IOS,ANDROID,WXAPP,OTHER    |          | false    | string             |                    |


**响应状态**:


| 状态码 | 说明 | schema           |
| ------ | ---- | ---------------- |
| 200    | OK   | ApiResultLoginVO |


**响应参数**:


| 参数名称                | 参数说明                       | 类型           | schema  |
| ----------------------- | ------------------------------ | -------------- | ------- |
| code                    | 自定义响应码                   | string         |         |
| message                 | 响应信息                       | string         |         |
| data                    |                                | LoginVO        | LoginVO |
| &emsp;&emsp;accessToken | access_token                   | string         |         |
| &emsp;&emsp;expireIn    | 授权令牌 access_token 的有效期 | integer(int64) |         |
| &emsp;&emsp;userInfo    |                                | object         |         |
| param                   | 额外参数                       | object         |         |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {
		"accessToken": "",
		"expireIn": 0,
		"userInfo": {}
	},
	"param": {}
}
```
