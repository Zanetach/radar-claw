## 雷达号密码注册


**接口地址**:`/api/app/user/register/ai-radar`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>自定义雷达号与密码注册，无手机号与短信;</p>



**请求示例**:


```javascript
{
  "radarNumber": "radar01",
  "password": "password123",
  "confirmPassword": "password123"
}
```


**请求参数**:


**请求参数**:


| 参数名称                    | 参数说明                                    | 请求类型 | 是否必须 | 数据类型                 | schema                   |
| --------------------------- | ------------------------------------------- | -------- | -------- | ------------------------ | ------------------------ |
| radarPasswordRegisterDTO    | 雷达号密码注册 DTO                          | body     | true     | RadarPasswordRegisterDTO | RadarPasswordRegisterDTO |
| &emsp;&emsp;radarNumber     | 雷达号（字母开头，6-20 位，字母数字下划线） |          | true     | string                   |                          |
| &emsp;&emsp;password        | 密码                                        |          | true     | string                   |                          |
| &emsp;&emsp;confirmPassword | 确认密码                                    |          | true     | string                   |                          |


**响应状态**:


| 状态码 | 说明 | schema        |
| ------ | ---- | ------------- |
| 200    | OK   | ApiResultLong |


**响应参数**:


| 参数名称 | 参数说明     | 类型           | schema         |
| -------- | ------------ | -------------- | -------------- |
| code     | 自定义响应码 | string         |                |
| message  | 响应信息     | string         |                |
| data     | 响应数据     | integer(int64) | integer(int64) |
| param    | 额外参数     | object         |                |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": 0,
	"param": {}
}
```
