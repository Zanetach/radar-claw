## APP短信登录


**接口地址**:`/api/auth/app/login/sms`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>App用户使用手机号和短信验证码登录，如果用户不存在则自动注册</p>



**请求示例**:


```javascript
{
  "phone": "13800138000",
  "smsCode": "123456",
  "clientId": "da184b31f1f94f37a0183a224e074da3",
  "source": "WXAPP"
}
```


**请求参数**:


**请求参数**:


| 参数名称             | 参数说明                                           | 请求类型 | 是否必须 | 数据类型       | schema         |
| -------------------- | -------------------------------------------------- | -------- | -------- | -------------- | -------------- |
| appSmsLoginDTO       | App用户短信登录DTO                                 | body     | true     | AppSmsLoginDTO | AppSmsLoginDTO |
| &emsp;&emsp;phone    | 手机号                                             |          | true     | string         |                |
| &emsp;&emsp;smsCode  | 短信验证码                                         |          | true     | string         |                |
| &emsp;&emsp;clientId | 客户端ID 固定值为 da184b31f1f94f37a0183a224e074da3 |          | true     | string         |                |
| &emsp;&emsp;source   | 登录来源,可用值:IOS,ANDROID,WXAPP,OTHER            |          | false    | string         |                |


**响应状态**:


| 状态码 | 说明 | schema           |
| ------ | ---- | ---------------- |
| 200    | OK   | ApiResultLoginVO |


**响应参数**:


| 参数名称                | 参数说明                       | 类型           | schema  |
| ----------------------- | ------------------------------ | -------------- | ------- |
| code                    | 自定义响应码                   | string         |         |
| message                 | 响应信息                       | string         |         |
| data                    |                                | LoginVO        | LoginVO |
| &emsp;&emsp;accessToken | access_token                   | string         |         |
| &emsp;&emsp;expireIn    | 授权令牌 access_token 的有效期 | integer(int64) |         |
| &emsp;&emsp;userInfo    |                                | object         |         |
| param                   | 额外参数                       | object         |         |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {
		"accessToken": "",
		"expireIn": 0,
		"userInfo": {}
	},
	"param": {}
}
```
