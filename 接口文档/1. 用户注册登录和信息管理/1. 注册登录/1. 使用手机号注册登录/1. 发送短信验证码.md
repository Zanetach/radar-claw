## 发送短信验证码


**接口地址**:`/api/auth/sms/send-code`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>用于登录、注册、找回密码等场景，验证码5分钟内有效</p>



**请求示例**:


```javascript
{
  "phone": "13800138000",
  "scene": "LOGIN"
}
```


**请求参数**:


**请求参数**:


| 参数名称          | 参数说明                                                     | 请求类型 | 是否必须 | 数据类型       | schema         |
| ----------------- | ------------------------------------------------------------ | -------- | -------- | -------------- | -------------- |
| sendSmsCodeDTO    | 发送短信验证码DTO                                            | body     | true     | SendSmsCodeDTO | SendSmsCodeDTO |
| &emsp;&emsp;phone | 手机号                                                       |          | true     | string         |                |
| &emsp;&emsp;scene | 验证码用途,可用值:LOGIN,REGISTER,RESET_PASSWORD,BIND_PHONE,CHANGE_PHONE,CHANGE_TRADE_PASSWORD,CHANGE_PASSWORD,LOGIN,REGISTER,RESET_PASSWORD,BIND_PHONE |          | true     | string         |                |


**响应状态**:


| 状态码 | 说明 | schema        |
| ------ | ---- | ------------- |
| 200    | OK   | ApiResultVoid |


**响应参数**:


| 参数名称 | 参数说明     | 类型   | schema |
| -------- | ------------ | ------ | ------ |
| code     | 自定义响应码 | string |        |
| message  | 响应信息     | string |        |
| data     | 响应数据     | object |        |
| param    | 额外参数     | object |        |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": {},
	"param": {}
}
```
