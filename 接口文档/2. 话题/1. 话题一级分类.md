## 【查询】话题一级分类


**接口地址**:`/api/app/topic/category/list`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>获取一级话题分类列表</p>



**请求参数**:


**请求参数**:


暂无


**响应状态**:


| 状态码 | 说明 | schema                       |
| ------ | ---- | ---------------------------- |
| 200    | OK   | ApiResultListTopicCategoryVO |


**响应参数**:


| 参数名称                 | 参数说明             | 类型           | schema          |
| ------------------------ | -------------------- | -------------- | --------------- |
| code                     | 自定义响应码         | string         |                 |
| message                  | 响应信息             | string         |                 |
| data                     | 响应数据             | array          | TopicCategoryVO |
| &emsp;&emsp;id           | 分类ID               | integer(int64) |                 |
| &emsp;&emsp;categoryName | 分类名称             | string         |                 |
| &emsp;&emsp;sortOrder    | 排序值（越大越靠前） | integer(int32) |                 |
| param                    | 额外参数             | object         |                 |


**响应示例**:
```javascript
{
	"code": "0000",
	"message": "SUCCESS",
	"data": [
		{
			"id": 0,
			"categoryName": "",
			"sortOrder": 0
		}
	],
	"param": {}
}
```
