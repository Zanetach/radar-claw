## 【分页】获取话题二级数据


**接口地址**:`/api/app/topic/page`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>分页获取二级话题</p>



**请求参数**:


**请求参数**:


| 参数名称   | 参数说明   | 请求类型 | 是否必须 | 数据类型 | schema |
| ---------- | ---------- | -------- | -------- | -------- | ------ |
| categoryId | 一级分类ID | query    | false    | string   |        |
| keyword    | 检索关键字 | query    | false    | string   |        |
| page       | 页数       | query    | false    | string   |        |
| limit      | 每页条数   | query    | false    | string   |        |


**响应状态**:


| 状态码 | 说明 | schema               |
| ------ | ---- | -------------------- |
| 200    | OK   | ApiResultTopicPageVO |


**响应参数**:


| 参数名称                                            | 参数说明             | 类型              | schema            |
| --------------------------------------------------- | -------------------- | ----------------- | ----------------- |
| code                                                | 自定义响应码         | string            |                   |
| message                                             | 响应信息             | string            |                   |
| data                                                |                      | TopicPageVO       | TopicPageVO       |
| &emsp;&emsp;topics                                  |                      | PageResultTopicVO | PageResultTopicVO |
| &emsp;&emsp;&emsp;&emsp;current                     | 当前页               | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;limit                       | 每页条数             | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;totalPage                   | 总页数               | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;total                       | 总条数               | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;rows                        | 结果集               | array             | TopicVO           |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;id              | 话题ID               | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;categoryId      | 所属一级分类ID       | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;categoryName    | 所属一级分类名称     | string            |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;topicName       | 话题名称             | string            |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;coverUrl        | 封面图               | string            |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;description     | 话题简介             | string            |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;readCount       | 阅读次数             | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;discussionCount | 讨论量               | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;followStatus    | 关注状态             | boolean           |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;createId        | 创建用户id           | integer(int64)    |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;createNickname  | 创建者昵称           | string            |                   |
| &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;sortOrder       | 排序值（越大越靠前） | integer(int32)    |                   |
| &emsp;&emsp;&emsp;&emsp;param                       | 额外参数             | object            |                   |
| param                                               | 额外参数             | object            |                   |
